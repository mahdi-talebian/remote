# مدیریت از راه دور کامپیوترهای کارمندان — SSH در شبکه محلی

این پکیج یک راه‌حل **بدون سرور و بدون اینترنت** برای اتصال امن SSH به کامپیوترهای ویندوزی کارمندان است — فقط با یک مودم مشترک:

```
[کامپیوتر تو]  ──همان مودم/روتر──>  [کامپیوتر کارمند: sshd]
      ssh it_remote@192.168.1.50
```

- ❌ بدون نیاز به اینترنت، بدون IP عمومی، بدون باز کردن پورت روی اینترنت، بدون سرویس واسط
- ✅ بعد از ری‌استارت کامپیوتر کارمند، خودکار دوباره در دسترس است (سرویس پس‌زمینه)
- ✅ کشف خودکار: کنسول کل شبکه را اسکن می‌کند — حتی اگر IP سیستم‌ها عوض شود
- ✅ احراز هویت با **رمز عبور**

> ⚠️ **محدودیت:** هر دو کامپیوتر باید **زیر یک مودم** باشند. اگر روزی کامپیوتر کارمند در شبکه‌ی دیگری باشد (مثلاً از خانه)، اتصال ممکن نیست.

---

## 🗂 فایل‌ها

| فایل | اجرا روی | کار |
|---|---|---|
| `deploy-employee.ps1` | **هر کامپیوتر کارمند** (یک‌بار، به‌عنوان Admin) | فعال‌سازی sshd، ساخت اکانت، فایروال شبکه محلی، چاپ آدرس SSH |
| `scan-network.ps1` | **کامپیوتر خودت** | اسکن شبکه و لیست همه آدرس‌های SSH، ذخیره در `ssh-addresses.txt` |
| `deploy-via-domain.ps1` | **کامپیوتر خودت** (اختیاری) | اجرای خودکار اسکریپت روی چند کامپیوتر از راه دور (WinRM/domain) |
| `gui/AdminConsole.ps1` (+ `.bat`) | **کامپیوتر خودت** | رابط گرافیکی مدیریت: اسکن شبکه، وضعیت آنلاین/آفلاین، اتصال با یک کلیک |
| `gui/SetupWizard.ps1` (+ `.bat`) | **هر کامپیوتر کارمند** | رابط گرافیکی استقرار: فرم ساده + لاگ زنده + نمایش آدرس SSH |

---

## 🖥 مرحله ۱ — استقرار روی کامپیوتر کارمند

ساده‌ترین راه: پوشه `gui` را به کامپیوتر کارمند ببرید و `SetupWizard.bat` را (به‌عنوان مدیر سیستم) اجرا کنید — فقط **نام دستگاه** و **رمز عبور** (حداقل ۸ کاراکتر) را وارد می‌کند.

یا با اسکریپت (PowerShell به‌عنوان Administrator):

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy-employee.ps1 `
  -AdminPassword "یک-رمز-قوی-انتخاب-کن!" `
  -Hostname "pc-01"
```

در پایان، آدرس SSH چاپ می‌شود و در `C:\ProgramData\RemoteAdmin\ssh-address.txt` هم ذخیره می‌شود:

```
REMOTE SSH ADDRESS  ->   ssh it_remote@192.168.1.50
```

> اسکریپت idempotent است؛ اجرای مجدد امن است. اگر `-Hostname` ندهی، نام کامپیوتر استفاده می‌شود.

---

## 🖥 مرحله ۲ — روی کامپیوتر خودت

- **گرافیکی:** `gui\AdminConsole.bat` را اجرا کنید و دکمه **«بروزرسانی»** را بزنید — کل شبکه اسکن می‌شود و همه سیستم‌های SSH-دار با وضعیت آنلاین/آفلاین لیست می‌شوند. **دوبار کلیک** روی هر ردیف = ترمینال SSH.
- **دستوری:** `powershell -ExecutionPolicy Bypass -File .\scan-network.ps1`

رمز ورود = همان `AdminPassword` که در مرحله ۱ انتخاب شد. اولین بار پیام امنیتی (fingerprint) را با `yes` تأیید کنید.

---

## 🛡 نکات امنیتی (حتماً بخوان)

1. **رمز قوی** برای اکانت `it_remote` — حداقل ۱۴ کاراکتر ترکیبی؛ این همان درِ ورود به کل سیستم است.
2. پورت ۲۲ روی **کل شبکه محلی** باز است — هر کسی داخل همان وای‌فای/شبکه می‌تواند تلاش ورود کند (رمز قوی = دفاع اصلی).
3. اکانت `it_remote` روی هر سیستم **Administrator** است — مراقب انتقال رمز/فایل‌ها باش.
4. اسکریپت پروفایل شبکه را از «Public» به «Private» تغییر می‌دهد (وگرنه ویندوز اتصال را می‌بندد).

## 🩺 عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| هیچ سیستمی در کنسول پیدا نمی‌شود | «AP isolation» مودم را خاموش کن (جداسازی کلاینت‌ها)؛ هر دو باید زیر یک مودم باشند |
| ویزارد موفق بود ولی در لیست نیست | پروفایل شبکه Windows هنوز Public است → ویزارد را دوباره اجرا کن (خودش Private می‌کند) |
| دیروز وصل می‌شد، امروز نه | IP عوض شده — فقط «بروزرسانی» بزن (اسکن پیداش می‌کند) |
| `Connection refused` | سرویس sshd خاموش است: `Get-Service sshd; Start-Service sshd` |
| `Permission denied` | رمز اشتباه؛ تغییر رمز: `Set-LocalUser it_remote -Password (Read-Host -AsSecureString)` |
| روتر/NAS هم در لیست می‌آید | طبیعی است — هر چیزی که پورت ۲۲ باز داشته باشد لیست می‌شود؛ ستون «نام دستگاه» کمک می‌کند |
| ویندوز قدیمی (مثلاً 7/8) | OpenSSH سرور رسمی ندارد؛ از MobaSSH یا Bitvise استفاده کن |

## 💡 نکته: IP ثابت با رزرو مودم (اختیاری)

اگر می‌خواهی آدرس سیستم‌ها هیچ‌وقت عوض نشود، در پنل مودم برای هر سیستم **DHCP Reservation** بگذار (MAC → IP ثابت). لازم نیست — چون کنسول با هر «بروزرسانی» IP جدید را پیدا می‌کند — ولی آدرس‌ها ثابت‌تر می‌شوند.

## 🧹 حذف کامل یک کامپیوتر

```powershell
# روی ماشین کارمند (Admin):
Remove-LocalUser it_remote
Get-Service sshd | Stop-Service; Set-Service sshd -StartupType Disabled
Remove-NetFirewallRule -DisplayName 'OpenSSH Server (LAN)'
```
